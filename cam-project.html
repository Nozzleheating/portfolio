Project 12

Cam Project

Problem
Engineering class assignment to create a device that converts rotary motion into linear motion.
Solution
Created a pear-shaped cam device that moves the numbers up and down as the shaft rotates.
Notes
Used Onshape for this project.

Mechanism

The cam profiles rotate on a shaft and lift each number, showing rotary motion converted into linear motion.
