Project 11

Bridge

Problem
Class project to design a bridge that could hold the most weight using balsa wood and wood glue.
Solution
Designed and built a Howe truss bridge that held 4.535 kg during testing.
Notes
Designed the layout in Fusion 360.

Build Process

The bridge combined a Fusion 360 layout with a balsa wood truss structure built for maximum load capacity.
